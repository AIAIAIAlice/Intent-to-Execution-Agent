# Demo Guide

本 Demo 用“电商自动化运营 Agent”作为示例，展示 Complex Task Agent 如何从模糊目标出发，逐步完成澄清、规划、执行、验收和交付。

## 体验路径

### Step 1：输入模糊目标

默认目标为：

```text
帮我做一个电商自动化运营 Agent，提升店铺销量
```

可以直接使用默认目标，也可以改成其他复杂任务目标。

### Step 2：开始澄清目标

点击“开始澄清目标”后，Demo 会进入需求澄清阶段。此时重点不是立即执行，而是让 Agent 识别缺失信息，并要求用户补充关键决策。

### Step 3：选择关键上下文

依次选择：

- 平台：如淘宝、抖音小店、小红书、Shopify、Amazon
- 运营目标：如拉新、提升转化、复购、清库存、提升客单价
- 自动化边界：只给建议、半自动执行、全自动执行

这些选择会影响后续计划、风险等级和确认要求。

### Step 4：生成并确认计划

点击“生成结构化计划”后，Agent 会把模糊目标转成任务计划。用户需要确认执行边界后，Agent 才进入执行阶段。

### Step 5：观察任务推进

执行过程中可以观察：

- 当前阶段
- 任务完成进度
- 事件日志
- 风险与权限状态
- 阶段交付物状态

### Step 6：暂停、恢复或人工接管

Demo 支持在执行过程中暂停任务，也支持人工接管。该能力用于展示复杂任务中用户与 Agent 的协作关系。

### Step 7：验收与交付

当阶段结果生成后，用户可以验收并继续交付。最终页面会展示核心交付物，并提供导出 Markdown 和复制结果的入口。

## 建议演示重点

- Agent 不会从模糊目标直接执行，而是先澄清。
- 执行计划需要用户确认。
- 高风险动作默认需要确认或人工介入。
- 任务进度、风险和事件日志始终可见。
- 最终交付后仍可进入下一轮优化。
